### Video Generation

Video generation is queued: you submit a prompt, get a generation ID back immediately, then poll
that ID until the video is ready. Expect one to fifteen minutes depending on the model and
duration. To see which models generate video, visit the
[Models](https://www.oxen.ai/ai/models?modalities=text-to-video) page and filter by "Text to Video".

<CodeGroup>

```bash cURL
# Enqueue the job and capture the generation id.
GEN_ID=$(curl -s -X POST \
  https://hub.oxen.ai/api/ai/queue \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -d '{
    "model": "kling-video-v2-6-pro-text-to-video",
    "prompt": "An ox walking in a field",
    "duration": 5
  }' | jq -r '.generations[0].generation_id')

# Poll until it finishes, then print the result.
while true; do
  STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
    "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
  case $STATUS in succeeded|failed|cancelled) break;; esac
  sleep 15
done

curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
  "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.result_url'
```

```python Python
import os
import requests
import time

HEADERS = {
    "Authorization": f"Bearer {os.getenv('OXEN_API_KEY')}",
    "Content-Type": "application/json",
}

enqueue = requests.post(
    "https://hub.oxen.ai/api/ai/queue",
    headers=HEADERS,
    json={
        "model": "kling-video-v2-6-pro-text-to-video",
        "prompt": "An ox walking in a field",
        "duration": 5,
    },
)
enqueue.raise_for_status()
generation_id = enqueue.json()["generations"][0]["generation_id"]

while True:
    data = requests.get(
        f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
        headers=HEADERS,
    ).json()
    if data["status"] in {"succeeded", "failed", "cancelled"}:
        break
    time.sleep(15)

print(f"Generated video: {data['result_url']}")
```

</CodeGroup>

## Parameters

- **model**: The model to generate with (for example `kling-video-v2-6-pro-text-to-video`)
- **prompt**: Text description of the video you want
- **duration**: Length in seconds (optional, defaults vary by model)

Every other parameter is the model's own. `GET /api/ai/models/:id` returns its schema, and the
[media generation reference](/inference-api/reference/async_queue) covers the queue itself: the
event stream, cancellation, retries, and how long result URLs stay valid.

Waiting on a poll loop for several minutes is wasteful. Subscribe to `GET /api/events` before you
enqueue and you get told the moment the file lands.
