### Image to Image

Image to image models take one or more images along with your prompt. The request is the same as
for [image generation](/examples/inference/image_generation), with `input_image` added. You get a
generation ID back right away and poll that ID until the image is ready.

Some of these models are built for editing. They change the image you give them and keep the rest,
and a few do a single job, like erasing an object, upscaling, or trying clothes on a person. Others
are generation models that also accept reference images, carrying a character, a product, or a style
from them into a new image. To see them all, visit the
[Models](https://www.oxen.ai/ai/models?modalities=image-to-image) page and filter by "Image to
image".

<CodeGroup>

```bash cURL
# Enqueue the edit and capture the generation id.
GEN_ID=$(curl -s -X POST \
  https://hub.oxen.ai/api/ai/queue \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -d '{
    "model": "qwen-image-edit",
    "input_image": "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png",
    "prompt": "Add a funny hat to the ox",
    "num_inference_steps": 28
  }' | jq -r '.generations[0].generation_id')

# Poll until it finishes, then print the result.
while true; do
  STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
    "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
  case $STATUS in succeeded|failed|cancelled) break;; esac
  sleep 3
done

curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
  "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.result_url'
```

```python Python
import os
import requests
import time

HEADERS = {
    "Authorization": f"Bearer {os.getenv('OXEN_API_KEY')}",
    "Content-Type": "application/json",
}

enqueue = requests.post(
    "https://hub.oxen.ai/api/ai/queue",
    headers=HEADERS,
    json={
        "model": "qwen-image-edit",
        "input_image": "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png",
        "prompt": "Add a funny hat to the ox",
        "num_inference_steps": 28,
    },
)
enqueue.raise_for_status()
generation_id = enqueue.json()["generations"][0]["generation_id"]

while True:
    data = requests.get(
        f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
        headers=HEADERS,
    ).json()
    if data["status"] in {"succeeded", "failed", "cancelled"}:
        break
    time.sleep(3)

print(f"Edited image: {data['result_url']}")
```

</CodeGroup>

Models that take several reference images accept an array in `input_image`:

```json
{
  "model": "qwen-image-edit-plus",
  "input_image": [
    "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png",
    "https://hub.oxen.ai/api/repos/elau/assets/file/main/paintings/Wanderer_above_the_Sea_of_Fog_Caspar_David_Friedrich_399x512.jpeg"
  ],
  "prompt": "Put the character from the first image into the scene from the second"
}
```

Whether a model wants one URL or an array is part of its schema, and either way the URL has to be
reachable without credentials, since the model downloads it.

## Parameters

- **model**: The model to use (for example `qwen-image-edit`)
- **input_image**: URL of the input image, or an array of URLs for models that take several
- **prompt**: Text description of the change or the image you want
- **num_inference_steps**: Number of inference steps (optional, defaults vary by model)

Each model takes its own parameters beyond these, and `GET /api/ai/models/:id` returns them. The
[queue reference](/inference-api/reference/async_queue) covers the event stream, cancellation,
retries, and how long result URLs stay valid.
