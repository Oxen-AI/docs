### Image Editing

Editing works like [image generation](/examples/inference/image_generation) with an image added to
the request. Pass its URL in `input_image` along with your prompt.

Some models are made for editing, like `qwen-image-edit`. Others generate new images and can take
reference images too, like Seedream and FLUX.2. To find them, filter the
[Models](https://www.oxen.ai/ai/models?modalities=image-to-image) page by "Image to image".

<CodeGroup>

```bash cURL
# Start the edit
GEN_ID=$(curl -s -X POST \
  https://hub.oxen.ai/api/ai/queue \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -d '{
    "model": "qwen-image-edit",
    "input_image": "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png",
    "prompt": "Add a funny hat to the ox",
    "num_inference_steps": 28
  }' | jq -r '.generations[0].generation_id')

# Wait for it to finish, then print the result
while true; do
  STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
    "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
  case $STATUS in succeeded|failed|cancelled) break;; esac
  sleep 3
done

curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
  "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.result_url'
```

```python Python
import os
import requests
import time

HEADERS = {
    "Authorization": f"Bearer {os.getenv('OXEN_API_KEY')}",
    "Content-Type": "application/json",
}

enqueue = requests.post(
    "https://hub.oxen.ai/api/ai/queue",
    headers=HEADERS,
    json={
        "model": "qwen-image-edit",
        "input_image": "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png",
        "prompt": "Add a funny hat to the ox",
        "num_inference_steps": 28,
    },
)
enqueue.raise_for_status()
generation_id = enqueue.json()["generations"][0]["generation_id"]

while True:
    data = requests.get(
        f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
        headers=HEADERS,
    ).json()
    if data["status"] in {"succeeded", "failed", "cancelled"}:
        break
    time.sleep(3)

print(f"Edited image: {data['result_url']}")
```

</CodeGroup>

Some models take several images. Pass an array:

```json
{
  "model": "qwen-image-edit-plus",
  "input_image": [
    "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png",
    "https://hub.oxen.ai/api/repos/elau/assets/file/main/paintings/Wanderer_above_the_Sea_of_Fog_Caspar_David_Friedrich_399x512.jpeg"
  ],
  "prompt": "Put the character from the first image into the scene from the second"
}
```

Image URLs must be public, since the model downloads them.

## Parameters

- **model**: Model name, for example `qwen-image-edit`
- **input_image**: Image URL, or an array of URLs
- **prompt**: What to change or create
- **num_inference_steps**: Number of inference steps (optional, defaults vary by model)

Models can take more parameters, listed in each model's
[API reference](/inference-api/reference/model-references). The
[queue reference](/inference-api/reference/async_queue) covers the rest of the queue API.
