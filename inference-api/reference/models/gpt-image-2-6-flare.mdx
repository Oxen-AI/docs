**Model ID:** `gpt-image-2-6-flare`

GPT Image 2.6 Flare is OpenAI's fast image generation and editing model, about 50% faster than GPT Image 2.5 Flare.

It generates from a prompt or edits up to 16 reference images, with markup, mask inpainting, transparent backgrounds, sizes up to 4K (3840x2160) and five quality tiers from low to max. From a prompt alone it can also render an animated GIF of 2 to 16 frames or a scalable SVG. It suits quick iteration, social content and product imagery; GPT Image 2.6 Sunburst suits detailed, many-round edits.

        ```bash cURL
        # Enqueue, capture the generation id.
        GEN_ID=$(curl -s -X POST https://hub.oxen.ai/api/ai/queue \

        }' | jq -r '.generations[0].generation_id')

        # Poll until the generation reaches a terminal status.
        while true; do
          STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
            "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
          echo "Status: $STATUS"
          case $STATUS in succeeded|failed|cancelled) break;; esac
          sleep 5
        done

        # Print the result.
        curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
          "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq .
        ```

        ```python Python
        import os
        import time
        import requests

        HEADERS = {
            "Content-Type": "application/json",
            "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
        }

        enqueue = requests.post(
            "https://hub.oxen.ai/api/ai/queue",
            headers=HEADERS,
            json={
                "model": "gpt-image-2-6-flare"
            },
        )
        enqueue.raise_for_status()
        generation_id = enqueue.json()["generations"][0]["generation_id"]

        while True:
            data = requests.get(
                f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
                headers=HEADERS,
            ).json()
            if data["status"] in {"succeeded", "failed", "cancelled"}:
                break
            time.sleep(5)

        if data["status"] == "succeeded":
            print(f"Result: {data['result_url']}")
        else:
            print(f"Generation {data['status']}: {data.get('error_message')}")
        ```

        ```bash cURL
              expect = 0
            }
          ' | jq .
        ```

        ```python Python
        import json
        import os
        import requests

        API_KEY = os.environ["OXEN_API_KEY"]
        AUTH = {"Authorization": f"Bearer {API_KEY}"}

        enqueue = requests.post(
            "https://hub.oxen.ai/api/ai/queue",
            headers={**AUTH, "Content-Type": "application/json"},
            json={
                "model": "gpt-image-2-6-flare"
            },
        )
        enqueue.raise_for_status()
        generation_id = enqueue.json()["generations"][0]["generation_id"]

        with requests.get(
            "https://hub.oxen.ai/api/events",
            headers=AUTH,
            stream=True,
        ) as stream:
            event_name = None
            for line in stream.iter_lines(decode_unicode=True):
                if line.startswith("event: "):
                    event_name = line.removeprefix("event: ")
                elif line.startswith("data: ") and event_name == "media_generation_completed":
                    payload = json.loads(line.removeprefix("data: "))
                    if payload.get("generation_id") == generation_id:
                        print(payload)
                        break
        ```

## Request parameters

### Optional parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `input_image` | `array<string>` | &mdash; | Up to 16 images to edit or draw from. |
| `markup` | `string` | &mdash; | Draw on Image 1 to show what to change. Text and arrows are read as instructions. Format: uri. |
| `mask` | `string` | &mdash; | Paint the part of Image 1 to change. Format: uri. |
| `lock_unmasked` | `boolean` | `true` | Only modify the pixels within the masked region. |
