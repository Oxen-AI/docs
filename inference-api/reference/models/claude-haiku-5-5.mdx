**Model ID:** `claude-haiku-5-5`

**Claude Haiku 5.5 is Anthropic's fast, low-cost Multimodal LLM for high-volume, latency-sensitive work.** It suits classification, routing, extraction, and subagent tasks, and succeeds Claude Haiku 4.5 with a much larger context window and output limit at a lower price.

Adaptive thinking is on by default and steered by the effort parameter (low through max, default medium). Sampling parameters such as temperature are not supported. Its tokenizer counts the same text as about 30% more tokens than Claude Haiku 4.5's. Prompts over 100,000 tokens cost five times as much per token as shorter ones. Safety classifiers may decline requests in sensitive domains, returning a refusal stop reason. It accepts text and images and has a reliable knowledge cutoff of June 2026.

| Metric             | Value              |
|--------------------|--------------------|
| Context Length     | 1,000,000 tokens   |
| Max Output         | 128,000 tokens     |
| Multilingual       | Yes                |
