**Model ID:** `bytedance-seedream-5-5-layers`

Seedream 5.5 Layers splits a single image into a clean base image and separate transparent PNG layers, one per element: subjects, objects, decorations and blocks of text. Each layer keeps its position on the base, so a poster, ad or product shot can be rebuilt and rearranged in a design tool.

Leave the prompt blank to split out every main element, or name the elements to pull apart. With text recognition on, each text layer also reports its wording, a similar font family and its color, ready for retyping or translation. A split returns up to 99 layers, with a ZIP of the base, every layer and a manifest of their names, order and positions.

        ```bash cURL
        # Poll until the generation reaches a terminal status.

          STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
            "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
          echo "Status: $STATUS"
          case $STATUS in succeeded|failed|cancelled) break;; esac
          sleep 5
        done

        # Print the result.
        curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
          "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq .
        ```

        ```python Python
        import os
        import time
        import requests

        HEADERS = {
            "Content-Type": "application/json",
            "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
        }

        enqueue = requests.post(
            "https://hub.oxen.ai/api/ai/queue",
            headers=HEADERS,
            json={
                "model": "bytedance-seedream-5-5-layers",
                "input_image": "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png"
            },
        )
        enqueue.raise_for_status()
        generation_id = enqueue.json()["generations"][0]["generation_id"]

        while True:
            data = requests.get(
                f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
                headers=HEADERS,
            ).json()
            if data["status"] in {"succeeded", "failed", "cancelled"}:
                break
            time.sleep(5)

        if data["status"] == "succeeded":
            print(f"Result: {data['result_url']}")
        else:
            print(f"Generation {data['status']}: {data.get('error_message')}")
        ```

        ```python Python
        import json
        import os
        import requests

        API_KEY = os.environ["OXEN_API_KEY"]
        AUTH = {"Authorization": f"Bearer {API_KEY}"}

        enqueue = requests.post(
            "https://hub.oxen.ai/api/ai/queue",
            headers={**AUTH, "Content-Type": "application/json"},
            json={
                "model": "bytedance-seedream-5-5-layers",
                "input_image": "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png"
            },
        )
        enqueue.raise_for_status()
        generation_id = enqueue.json()["generations"][0]["generation_id"]

        with requests.get(
            "https://hub.oxen.ai/api/events",
            headers=AUTH,
            stream=True,
        ) as stream:
            event_name = None
            for line in stream.iter_lines(decode_unicode=True):
                if line.startswith("event: "):
                    event_name = line.removeprefix("event: ")
                elif line.startswith("data: ") and event_name == "media_generation_completed":
                    payload = json.loads(line.removeprefix("data: "))
                    if payload.get("generation_id") == generation_id:
                        print(payload)
                        break
        ```

## Request parameters

### Required parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `input_image` | `string` | &mdash; | The image to split into layers. Format: uri. |

### Optional parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `prompt` | `string` | &mdash; | Optional. Name the elements to split out, such as "the cyclist, the scooter and the bakery sign". Leave blank to split out every main element. |
| `max_layers` | `integer` | `10` | The most layers to return, not counting the base image. Higher values split the image more finely, and each layer is billed as an image. Range: 1 – 99. |
| `text_recognition` | `boolean` | `true` | Read each text layer's wording, a similar font family and its color. |
| `output_format` | `string` | `"png"` | Format of the base image. One of: png, jpeg. |
| `watermark` | `boolean` | `false` | Whether to add an 'AI generated' watermark. |
| `layer_decomposition` | `boolean` | `true` | Split Into Layers |
