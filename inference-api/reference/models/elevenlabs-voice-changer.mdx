**Model ID:** `elevenlabs-voice-changer`

Eleven Voice Changer re-voices a speech recording in a different voice while keeping the original timing, emotion, and delivery.

The performance in the source clip drives the output, so whispers, laughs, pacing, and emphasis carry through to the new voice. It works across 29 languages and can strip background noise from the input before converting. It suits replacing scratch voiceover, giving one performer several characters, anonymizing speakers, and building paired speech datasets. Each clip can be up to 5 minutes long.

| Metric       | Value                |
|--------------|----------------------|
| Max Input    | 5 minutes            |
| Multilingual | Yes, 29 languages    |

### Optional parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `remove_background_noise` | `boolean` | `false` | Isolate the speech from background noise before converting it. |
| `stability` | `number` | `0.5` | Lower values give more varied delivery; higher values stay closer to a fixed baseline. Range: 0.0 – 1.0. |
| `similarity_boost` | `number` | `0.75` | How closely the output follows the target voice. Range: 0.0 – 1.0. |
| `seed` | `integer` | &mdash; | Optional seed for best-effort deterministic output. Range: 0 – 4294967295. |
