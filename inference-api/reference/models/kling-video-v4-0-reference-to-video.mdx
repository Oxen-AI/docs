**Model ID:** `kling-video-v4-0-reference-to-video`

Kling 4.0 generates and edits video guided by up to 15 references: images, videos, and consistent character or object elements, with native audio in single takes of 3 to 30 seconds at 720p or 1080p. It keeps faces, outfits, and products consistent with the references while following the motion and camera of a reference video.

Add a video to edit and describe what to change and what to keep: swap an object, restyle a scene, or rewrite a line of dialogue, and the edit runs at the source video's length by default. Refer to inputs in the prompt as @image_1, @video_1, and @element_1, and say how each should be used, such as "keep the face and outfit from @image_1" or "follow the dance moves in @video_2 but not its background".

        ```bash cURL
        # Enqueue, capture the generation id.
        GEN_ID=$(curl -s -X POST https://hub.oxen.ai/api/ai/queue \
          -H "Content-Type: application/json" \
          -H "Authorization: Bearer $OXEN_API_KEY" \
          -d '{
          "model": "kling-video-v4-0-reference-to-video",
          "prompt": "<prompt>"
        }' | jq -r '.generations[0].generation_id')

        # Poll until the generation reaches a terminal status.
        while true; do
          STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
            "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
          echo "Status: $STATUS"
          case $STATUS in succeeded|failed|cancelled) break;; esac
          sleep 5
        done

        # Print the result.
        curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
          "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq .
        ```

        ```python Python
        import os
        import time
        import requests

        HEADERS = {
            "Content-Type": "application/json",
            "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
        }

        enqueue = requests.post(
            "https://hub.oxen.ai/api/ai/queue",
            headers=HEADERS,
            json={
                "model": "kling-video-v4-0-reference-to-video",
                "prompt": "<prompt>"
            },
        )
        enqueue.raise_for_status()
        generation_id = enqueue.json()["generations"][0]["generation_id"]

        while True:
            data = requests.get(
                f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
                headers=HEADERS,
            ).json()
            if data["status"] in {"succeeded", "failed", "cancelled"}:
                break
            time.sleep(5)

        if data["status"] == "succeeded":
            print(f"Result: {data['result_url']}")
        else:
            print(f"Generation {data['status']}: {data.get('error_message')}")
        ```

        ```bash cURL
        # Enqueue, capture the generation id.
        GEN_ID=$(curl -s -X POST https://hub.oxen.ai/api/ai/queue \
          -H "Content-Type: application/json" \
          -H "Authorization: Bearer $OXEN_API_KEY" \
          -d '{
          "model": "kling-video-v4-0-reference-to-video",
          "prompt": "<prompt>"
        }' | jq -r '.generations[0].generation_id')

        # Stream the SSE channel, grab the data line that follows a
        # media_generation_completed event for our id, and pretty-print it.
        curl -sN -H "Authorization: Bearer $OXEN_API_KEY" https://hub.oxen.ai/api/events \
          | awk -v id="$GEN_ID" '
            /^event: media_generation_completed$/ { expect=1; next }
            /^data: / && expect {
              payload = substr($0, 7)
              if (index(payload, "\"generation_id\":\"" id "\"")) { print payload; exit }
              expect = 0
            }
          ' | jq .
        ```

        ```python Python
        import json
        import os
        import requests

        API_KEY = os.environ["OXEN_API_KEY"]
        AUTH = {"Authorization": f"Bearer {API_KEY}"}

        enqueue = requests.post(
            "https://hub.oxen.ai/api/ai/queue",
            headers={**AUTH, "Content-Type": "application/json"},
            json={
                "model": "kling-video-v4-0-reference-to-video",
                "prompt": "<prompt>"
            },
        )
        enqueue.raise_for_status()
        generation_id = enqueue.json()["generations"][0]["generation_id"]

        with requests.get(
            "https://hub.oxen.ai/api/events",
            headers=AUTH,
            stream=True,
        ) as stream:
            event_name = None
            for line in stream.iter_lines(decode_unicode=True):
                if line.startswith("event: "):
                    event_name = line.removeprefix("event: ")
                elif line.startswith("data: ") and event_name == "media_generation_completed":
                    payload = json.loads(line.removeprefix("data: "))
                    if payload.get("generation_id") == generation_id:
                        print(payload)
                        break
        ```

## Request parameters

### Required parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `prompt` | `string` | &mdash; | Describe what to generate or change, and how to use each reference: @image_1, @video_1, @element_1, and so on. |

### Optional parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `input_images` | `array<string>` | &mdash; | Reference images for characters, objects, scenes, or style. Up to 10 images in total, including first and last frames. |
| `input_video` | `string` | &mdash; | Video to edit. Describe what to change and what to keep. Format: uri. |
| `input_videos` | `array<string>` | &mdash; | Videos whose motion, camera, or style guide the output. Up to 5 videos including the video to edit. |
| `elements` | `array<object>` | &mdash; | Characters or objects to keep consistent, each from a front view plus other angles. Up to 7 elements. |
| `input_image` | `string` | &mdash; | Optional image the video starts on. Format: uri. |
| `tail_image_url` | `string` | &mdash; | Optional image the video ends on. Format: uri. |
| `aspect_ratio` | `string` | `"adaptive"` | Aspect Ratio One of: adaptive, 16:9, 9:16, 1:1, 21:9. |
| `resolution` | `string` | `"1080p"` | Resolution One of: 720p, 1080p. |
| `duration` | `['integer', 'string']` | `"auto"` | Duration Range: 3 – 30. |
