**Model ID:** `qwen-image-3-pro`

Qwen Image 3.0 Pro is the Pro tier of Alibaba's Qwen Image 3.0 series, a closed model that handles text-to-image generation and image editing in one endpoint and is built for dense, layout-heavy work such as posters, documents, infographics, and annotated images.

It reads prompts up to 4,500 tokens, renders legible text down to about 10 pixels in 12 languages, and can reason about the prompt before rendering. It takes up to three input images for edits and composition, outputs any size from 512x512 to 2048x2048 total pixels, and picks a resolution from the prompt when none is set. Compared with the standard 3.0 tier it trades speed for fidelity on complex scenes and small text.

Weights are not published.

| Metric             | Value                  |
|--------------------|------------------------|
| Context Length     | 4,500 tokens           |
| Max Resolution     | 2048x2048 (2K)         |
| Multilingual       | Yes (12 languages)     |

        ```bash cURL
        # Enqueue, capture the generation id.
        GEN_ID=$(curl -s -X POST https://hub.oxen.ai/api/ai/queue \

          -H "Authorization: Bearer $OXEN_API_KEY" \
          -d '{
          "model": "qwen-image-3-pro",
          "prompt": "<prompt>"
        }' | jq -r '.generations[0].generation_id')

        # Poll until the generation reaches a terminal status.
        while true; do
          STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
            "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
          echo "Status: $STATUS"
          case $STATUS in succeeded|failed|cancelled) break;; esac
          sleep 5
        done

        # Print the result.
        curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
          "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq .
        ```

        ```python Python
        import os
        import time
        import requests

        HEADERS = {
            "Content-Type": "application/json",
            "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
        }

        enqueue = requests.post(
            "https://hub.oxen.ai/api/ai/queue",
            headers=HEADERS,
            json={
                "model": "qwen-image-3-pro",
                "prompt": "<prompt>"
            },
        )
        enqueue.raise_for_status()
        generation_id = enqueue.json()["generations"][0]["generation_id"]

        while True:
            data = requests.get(
                f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
                headers=HEADERS,
            ).json()
            if data["status"] in {"succeeded", "failed", "cancelled"}:
                break
            time.sleep(5)

        if data["status"] == "succeeded":
            print(f"Result: {data['result_url']}")
        else:
            print(f"Generation {data['status']}: {data.get('error_message')}")
        ```

        ```bash cURL
        # Stream the SSE channel, grab the data line that follows a
        # media_generation_completed event for our id, and pretty-print it.
        curl -sN -H "Authorization: Bearer $OXEN_API_KEY" https://hub.oxen.ai/api/events \
          | awk -v id="$GEN_ID" '
            /^event: media_generation_completed$/ { expect=1; next }
            /^data: / && expect {
              payload = substr($0, 7)
              if (index(payload, "\"generation_id\":\"" id "\"")) { print payload; exit }
              expect = 0
            }
          ' | jq .
        ```

        ```python Python
        import json
        import os
        import requests

        API_KEY = os.environ["OXEN_API_KEY"]
        AUTH = {"Authorization": f"Bearer {API_KEY}"}

        enqueue = requests.post(
            "https://hub.oxen.ai/api/ai/queue",
            headers={**AUTH, "Content-Type": "application/json"},
            json={
                "model": "qwen-image-3-pro",
                "prompt": "<prompt>"
            },
        )
        enqueue.raise_for_status()
        generation_id = enqueue.json()["generations"][0]["generation_id"]

        with requests.get(
            "https://hub.oxen.ai/api/events",
            headers=AUTH,
            stream=True,
        ) as stream:
            event_name = None
            for line in stream.iter_lines(decode_unicode=True):
                if line.startswith("event: "):
                    event_name = line.removeprefix("event: ")
                elif line.startswith("data: ") and event_name == "media_generation_completed":
                    payload = json.loads(line.removeprefix("data: "))
                    if payload.get("generation_id") == generation_id:
                        print(payload)
                        break
        ```

## Request parameters

### Required parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `prompt` | `string` | &mdash; | Text prompt describing the image to generate, or the edit to apply. Up to 4,500 tokens. Use @Image1, @Image2, etc. to reference the input images. |

### Optional parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `input_images` | `array<string>` | &mdash; | Optional input images to edit or combine. The output keeps the aspect ratio of the last image unless an aspect ratio is chosen. Reference them in the prompt as @Image1, @Image2, etc. Up to 3 images. |
| `aspect_ratio` | `string` | `"auto"` | Aspect Ratio One of: auto, 16:9, 9:16, 1:1, 4:3, 3:4. |
| `resolution` | `string` | `"2K"` | Resolution One of: 1K, 2K. |
| `num_images` | `integer` | `1` | Number of images to generate, 1 to 6. Only the first is returned; all are billed. Range: 1 – 6. |
| `enable_prompt_expansion` | `boolean` | `true` | Let the model rewrite the prompt with more detail before rendering. Turn off for tighter control over the wording. |
| `enable_thinking` | `boolean` | `true` | Reason about the prompt before rendering. Improves quality on complex layouts and long prompts at the cost of generation time. Requires prompt expansion. |
| `negative_prompt` | `string` | &mdash; | What to keep out of the image. |
| `seed` | `integer` | &mdash; | Seed for reproducible generation, 0 to 2147483647. |
| `watermark` | `boolean` | `false` | Add an AI-generated watermark in the bottom-right corner. |
