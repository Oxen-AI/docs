**Model ID:** `heygen-avatar-6-turbo-text-to-video`

HeyGen Avatar 6 Turbo, the faster, lower-cost tier of Avatar 6, turns a script into a video of a HeyGen stock presenter speaking it, with lip sync, facial expression, and hand gestures generated from what is being said. The model follows the meaning of the speech, so the presenter points, counts, and gestures in step with the script.

Pick a presenter from HeyGen's public avatar library, in office, studio, sofa, and outdoor settings, and a library voice to read the script. Or upload recorded speech and the presenter lip-syncs to it in place of the script and voice. An optional motion prompt directs gestures, expression, and posture in plain language, such as "Smile warmly and use small, open-handed gestures while speaking."

Output is 1080p or 2K at 25 fps in 16:9, 9:16, 1:1, 4:5, or 5:4. The video runs as long as the speech and is billed per second of output, with 2K at a higher rate. It suits training and explainer videos, product walkthroughs, sales outreach, and social clips. Use it for drafts, iteration, and high-volume work; Avatar 6 takes the same inputs at higher fidelity.

        ```bash cURL
        # Poll until the generation reaches a terminal status.
        while true; do
          STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
            "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
          echo "Status: $STATUS"
          case $STATUS in succeeded|failed|cancelled) break;; esac
          sleep 5
        done

        # Print the result.
        curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
          "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq .
        ```

        ```python Python
        import os
        import time
        import requests

        HEADERS = {
            "Content-Type": "application/json",
            "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
        }

        enqueue = requests.post(
            "https://hub.oxen.ai/api/ai/queue",
            headers=HEADERS,
            json={
                "model": "heygen-avatar-6-turbo-text-to-video"
            },
        )
        enqueue.raise_for_status()
        generation_id = enqueue.json()["generations"][0]["generation_id"]

        while True:
            data = requests.get(
                f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
                headers=HEADERS,
            ).json()
            if data["status"] in {"succeeded", "failed", "cancelled"}:
                break
            time.sleep(5)

        if data["status"] == "succeeded":
            print(f"Result: {data['result_url']}")
        else:
            print(f"Generation {data['status']}: {data.get('error_message')}")
        ```

        ```bash cURL
        # Enqueue, capture the generation id.
        GEN_ID=$(curl -s -X POST https://hub.oxen.ai/api/ai/queue \
        ```

        ```bash cURL
        }' | jq -r '.generations[0].generation_id')

        # Stream the SSE channel, grab the data line that follows a
        # media_generation_completed event for our id, and pretty-print it.
        curl -sN -H "Authorization: Bearer $OXEN_API_KEY" https://hub.oxen.ai/api/events \
          | awk -v id="$GEN_ID" '
            /^event: media_generation_completed$/ { expect=1; next }
            /^data: / && expect {
              payload = substr($0, 7)
              if (index(payload, "\"generation_id\":\"" id "\"")) { print payload; exit }
              expect = 0
            }
          ' | jq .
        ```

        ```python Python
        import json
        import os
        import requests

        API_KEY = os.environ["OXEN_API_KEY"]
        AUTH = {"Authorization": f"Bearer {API_KEY}"}

        enqueue = requests.post(
            "https://hub.oxen.ai/api/ai/queue",
            headers={**AUTH, "Content-Type": "application/json"},
            json={
                "model": "heygen-avatar-6-turbo-text-to-video"
            },
        )
        enqueue.raise_for_status()
        generation_id = enqueue.json()["generations"][0]["generation_id"]

        with requests.get(
            "https://hub.oxen.ai/api/events",
            headers=AUTH,
            stream=True,
        ) as stream:
            event_name = None
            for line in stream.iter_lines(decode_unicode=True):
                if line.startswith("event: "):
                    event_name = line.removeprefix("event: ")
                elif line.startswith("data: ") and event_name == "media_generation_completed":
                    payload = json.loads(line.removeprefix("data: "))
                    if payload.get("generation_id") == generation_id:
                        print(payload)
                        break
        ```
