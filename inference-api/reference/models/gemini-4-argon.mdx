**Model ID:** `gemini-4-argon`

**gemini-4-argon is a Multimodal LLM.** It is Google's efficient Gemini 4 reasoning model, delivering Gemini 4 intelligence with faster responses and fewer tokens spent per turn than Gemini 4 Carbon.

Some other noteworthy features of gemini-4-argon include configurable thinking levels (low, medium, and high, with medium as the default), structured output, function calling, code execution, search grounding, URL context, file search, and computer use. It accepts text, images, audio, video, and PDFs and outputs text. It fits agents and coding assistants that make many calls per task, where each turn's latency and cost add up.

| Metric             | Value              |
|--------------------|--------------------|
| Context Length     | 1M tokens          |
| Max Output         | 64K tokens         |
| Multilingual       | Yes                |

## Example request

<Tip>
  Use the [Workbench](https://www.oxen.ai/ai/workbench?model=gemini-4-argon) as a request builder: configure parameters for this model in the UI, then open the **API** tab to copy the exact cURL or Python call.

<CodeGroup>

```bash cURL
curl -X POST https://hub.oxen.ai/api/ai/audio/transcriptions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -d '{
  "model": "gemini-4-argon",
  "audio_url": "https://example.com/audio.mp3"
}'
```

```python Python
import os
import requests

response = requests.post(
    "https://hub.oxen.ai/api/ai/audio/transcriptions",
    headers={
        "Content-Type": "application/json",
        "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
    },
    json={
        "model": "gemini-4-argon",
        "audio_url": "https://example.com/audio.mp3"
    },
)
response.raise_for_status()
print(response.json())
```
