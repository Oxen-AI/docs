**Model ID:** `elevenlabs-sound-effects-v2`

Eleven Sound Effects v2 generates sound effects, ambiences, and short musical stingers from a text description.

Describe the sound and its character, such as "heavy wooden door creaking open in a stone hallway", and the model returns a clip of up to 30 seconds, or picks a length from the prompt. Loop mode produces clips that repeat seamlessly for ambiences and game audio, and a prompt-influence control trades variety for closer adherence to the description. It suits foley for video, game assets, UI sounds, and adding audio to silent video generations.

| Metric     | Value       |
|------------|-------------|
| Max Output | 30 seconds  |

## Request parameters

### Required parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `prompt` | `string` | &mdash; | Describe the sound, its source, and the space it is in. |

### Optional parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `duration` | `number` | `5` | Duration Range: 0.5 – 30. |
| `loop` | `boolean` | `false` | Make a clip that repeats seamlessly. |
| `prompt_influence` | `number` | `0.3` | Higher values follow the prompt more closely with less variation between generations. Range: 0.0 – 1.0. |
