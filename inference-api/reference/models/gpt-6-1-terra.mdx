**Model ID:** `gpt-6-1-terra`

GPT 6.1 Terra is OpenAI's mid-tier GPT-6.1 model, pairing visual reasoning and precise computer use with clear, natural writing at a low per-token price. It succeeds GPT 5.6 Terra and runs agentic tasks considerably faster than GPT 6.1 Sol and GPT 6 Astra, which remain the choice for the most complex coding work.

It accepts text and images and supports configurable reasoning effort (none, low, medium, high, xhigh, and max), streaming, structured outputs, and function calling, with the web search, file search, image generation, code interpreter, hosted shell, apply patch, skills, computer use, MCP, and tool search tools. It suits high-volume coding, computer-use agents, document and screenshot understanding, and everyday writing and analysis.

| Metric             | Value              |
|--------------------|--------------------|
| Context Length     | 1,050,000 tokens   |
| Max Output Tokens  | 128,000 tokens     |
| Knowledge Cutoff   | Jun 1, 2026        |
| Multilingual       | Yes                |
