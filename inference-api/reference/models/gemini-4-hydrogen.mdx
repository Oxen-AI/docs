**Model ID:** `gemini-4-hydrogen`

**gemini-4-hydrogen is a Multimodal LLM.** It is Google's fast, efficient Gemini 4 model for everyday coding and agentic workflows. Google reports that it makes more than five times fewer fabricated claims than Gemini 3.8 Flash.

Some other noteworthy features of gemini-4-hydrogen include four thinking levels (low, medium, high, and xhigh, with high as the default), structured output, function calling, code execution, search grounding, URL context, file search, and computer use. It accepts text, images, audio, video, and PDFs and outputs text, and is priced flat across its full 1M token context.

| Metric             | Value              |
|--------------------|--------------------|
| Context Length     | 1M tokens          |
| Max Output         | 64K tokens         |
| Multilingual       | Yes                |

<CodeGroup>

```bash cURL
curl -X POST https://hub.oxen.ai/api/ai/audio/transcriptions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -d '{
  "model": "gemini-4-hydrogen",
  "audio_url": "https://example.com/audio.mp3"
}'
```

```python Python
import os
import requests

response = requests.post(
    "https://hub.oxen.ai/api/ai/audio/transcriptions",
    headers={
        "Content-Type": "application/json",
        "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
    },
    json={
        "model": "gemini-4-hydrogen",
        "audio_url": "https://example.com/audio.mp3"
    },
)
response.raise_for_status()
print(response.json())
```
