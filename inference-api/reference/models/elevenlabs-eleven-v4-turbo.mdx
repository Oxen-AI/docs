**Model ID:** `elevenlabs-eleven-v4-turbo`

Eleven v4 Turbo is the low-latency variant of Eleven v4, producing expressive speech in more than 90 languages at about 100 ms median inference latency.

It shares Eleven v4's audio tags, voice settings, and language coverage, so `[whispering]`, `[laughing]`, and similar tags direct delivery the same way. It fits voice agents, assistants, interactive characters, and bulk narration where speed and cost matter. A single request takes up to 10,000 characters.

| Metric         | Value                    |
|----------------|--------------------------|
| Context Length | 10,000 characters        |
| Multilingual   | Yes, 90+ languages       |

### Optional parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `language_code` | `string` | &mdash; | Optional ISO 639-1 language code (e.g. en, es, ja) to force the language and its text normalization. Leave empty to detect it from the text. |
| `stability` | `number` | `0.5` | Lower values give more varied, expressive delivery; higher values keep the performance consistent across generations. Range: 0.0 – 1.0. |
| `similarity_boost` | `number` | `0.75` | How closely the output follows the voice. Higher values match it more closely at some cost to naturalness. Range: 0.0 – 1.0. |
| `apply_text_normalization` | `string` | `"auto"` | Whether numbers, dates, and abbreviations are spelled out before speaking. One of: auto, on, off. |
| `seed` | `integer` | &mdash; | Optional seed for best-effort deterministic output. Range: 0 – 4294967295. |
