**Model ID:** `gpt-5-6-luna`

GPT 5.6 Luna is the GPT-5.6 model optimized for cost-sensitive, high-volume workloads. It is the most efficient and affordable member of the GPT-5.6 family while retaining the family's token efficiency, frontend design quality, and intent understanding.

It supports configurable reasoning effort (none, low, medium, high, xhigh, and max), a pro reasoning mode for quality-first tasks, programmatic tool calling, persisted reasoning across turns, and a broad tool set including functions, web search, file search, and computer use.

| Metric             | Value              |
|--------------------|--------------------|
| Parameter Count    | Unknown            |
| Mixture of Experts | Unknown            |
| Context Length     | 1,050,000 tokens   |
| Max Output Tokens  | 128,000 tokens     |
| Knowledge Cutoff   | Feb 16, 2026       |
| Multilingual       | Yes                |
| Quantized*         | Unknown            |

*_Quantization is specific to the inference provider and the model may be offered with different quantization levels by other providers._
