**Model ID:** `elevenlabs-music-v2-5-composition`

Eleven Music v2.5 with a composition plan builds a song section by section, with its own styles, length, and lyrics for each part.

Set the styles the whole song should have and avoid, then lay out sections such as intro, verse, chorus, and bridge, each with its own direction, duration, and lyric lines. Compared with a single prompt this gives exact control over structure and timing, which suits scoring to picture, songs with set lyrics, and tracks that have to hit a length. The track runs as long as its sections add up to, up to 10 minutes.

| Metric       | Value                                   |
|--------------|-----------------------------------------|
| Max Output   | 10 minutes, up to 30 sections           |
| Multilingual | Yes (lyrics in many languages)          |

## Request parameters

### Required parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `styles` | `string` | &mdash; | Styles and directions for the whole song, separated by commas, e.g. warm indie folk, fingerpicked acoustic guitar, 92 BPM. |
| `sections` | `array<object>` | &mdash; | The song's sections in order. Up to 30; they add up to the song's length. |

### Optional parameters

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `exclude_styles` | `string` | &mdash; | Styles the song should avoid, separated by commas. |
| `seed` | `integer` | &mdash; | Optional seed. The same seed and plan give more consistent results, though not identical ones. Range: 0 – 2147483647. |
