**Model ID:** `claude-fable-5`

**Claude Fable 5 is Anthropic's most capable widely released model, introducing the Claude 5 generation for demanding reasoning and long-horizon agentic work.** It is built to sustain days-long, complex, and asynchronous tasks that earlier models could not, with strong performance across software engineering, knowledge work, vision, and computer use.

Claude Fable 5 is a Mythos-class model made safe for general use, with conservative safeguards in cybersecurity, biology, and chemistry. Flagged requests in those domains can be routed to Claude Opus 4.8 via server-side fallback. It uses adaptive thinking (always on), does not support extended thinking, and ships with a native 1M-token context window and up to 128k output tokens.

| Metric             | Value              |
|--------------------|--------------------|
| Parameter Count    | Unknown            |
| Mixture of Experts | Unknown            |
| Context Length     | 1,000,000 tokens   |
| Max Output         | 128,000 tokens     |
| Multilingual       | Yes                |
| Quantized*         | Unknown            |

*_Quantization is specific to the inference provider and the model may be offered with different quantization levels by other providers._
