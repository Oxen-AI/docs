**Model ID:** `claude-opus-5-5`

**Claude Opus 5.5 is Anthropic's Opus-tier Multimodal LLM for complex coding, long-running agents, and knowledge work.** It combines adaptive thinking with improved token efficiency and faster output than Claude Opus 5, while supporting text and image inputs.

The model is designed for high-autonomy work such as codebase migrations, software audits, research, and multi-step professional workflows. It includes the safeguards Anthropic applies to its most capable models; use cases involving biology or cybersecurity may be subject to additional access controls.

| Metric             | Value              |
|--------------------|--------------------|
| Context Length     | 1,000,000 tokens   |
| Max Output         | 128,000 tokens     |
| Multilingual       | Yes                |

    import os
    import requests
