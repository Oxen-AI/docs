Image generation runs through the media queue. You submit a job, get a generation ID back right
away, then poll that ID until the image is ready, usually within 5 to 30 seconds.

## Generate an image

<CodeGroup>

```python Python
import os
import requests
import time

HEADERS = {
    "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
    "Content-Type": "application/json",
}

enqueue = requests.post(
    "https://hub.oxen.ai/api/ai/queue",
    headers=HEADERS,
    json={
        "model": "black-forest-labs-flux-2-klein-4b",
        "prompt": "A red cube on a white background, minimal",
    },
)
enqueue.raise_for_status()
generation_id = enqueue.json()["generations"][0]["generation_id"]
print(f"Enqueued {generation_id}")

while True:
    data = requests.get(
        f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
        headers=HEADERS,
    ).json()
    print(f"  {data['status']}")
    if data["status"] in {"succeeded", "failed", "cancelled"}:
        break
    time.sleep(3)

if data["status"] != "succeeded":
    raise SystemExit(f"{data['status']}: {data['error_message']}")

with open("output.png", "wb") as f:
    f.write(requests.get(data["result_url"]).content)
print("Saved output.png")
```

```bash cURL
# Enqueue and capture the generation id.
GEN_ID=$(curl -s -X POST https://hub.oxen.ai/api/ai/queue \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "black-forest-labs-flux-2-klein-4b",
    "prompt": "A red cube on a white background, minimal"
  }' | jq -r '.generations[0].generation_id')

# Poll until it finishes.
while true; do
  STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
    "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
  echo "$STATUS"
  case $STATUS in succeeded|failed|cancelled) break;; esac
  sleep 3
done

# Download the result.
curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
  "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.result_url' \
  | xargs curl -o output.png
```

</CodeGroup>

## Edit an image

Editing is the same request with an image to work from. Pass `input_image` and pick a model that
takes images as input.

<CodeGroup>

```python Python
import os
import requests

response = requests.post(
    "https://hub.oxen.ai/api/ai/queue",
    headers={
        "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "model": "qwen-image-edit",
        "prompt": "Make the background blue",
        "input_image": "https://example.com/my-photo.jpg",
    },
)

print(response.json())
```

```bash cURL
curl -X POST https://hub.oxen.ai/api/ai/queue \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-image-edit",
    "prompt": "Make the background blue",
    "input_image": "https://example.com/my-photo.jpg"
  }'
```

</CodeGroup>

The `input_image` URL has to be reachable without credentials, since the model downloads it. Some
models take an array of URLs instead of one; the model's own reference says which.

## Generate several at once

`num_generations` queues up to 4 copies of the same request in one call, each with its own ID.

```bash
curl -X POST https://hub.oxen.ai/api/ai/queue \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "black-forest-labs-flux-2-klein-4b",
    "prompt": "Abstract geometric pattern in blue and gold",
    "num_generations": 4
  }'
```
