Generate videos with the Oxen.ai API. Each request returns a generation ID right away, and you poll
it until the video is ready. Videos can take several minutes.

## Generate a video

<CodeGroup>

```python Python
import os
import requests
import time

HEADERS = {
    "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
    "Content-Type": "application/json",
}

enqueue = requests.post(
    "https://hub.oxen.ai/api/ai/queue",
    headers=HEADERS,
    json={
        "model": "kling-video-v2-6-pro-text-to-video",
        "prompt": "A red balloon floating upward through blue sky",
        "duration": 5,
    },
)
enqueue.raise_for_status()
generation_id = enqueue.json()["generations"][0]["generation_id"]
print(f"Enqueued {generation_id}")

while True:
    data = requests.get(
        f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
        headers=HEADERS,
    ).json()
    print(f"  {data['status']}")
    if data["status"] in {"succeeded", "failed", "cancelled"}:
        break
    time.sleep(15)

if data["status"] != "succeeded":
    raise SystemExit(f"{data['status']}: {data['error_message']}")

with open("output.mp4", "wb") as f:
    f.write(requests.get(data["result_url"]).content)
print("Saved output.mp4")
```

```bash cURL
# Start the generation
GEN_ID=$(curl -s -X POST https://hub.oxen.ai/api/ai/queue \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-video-v2-6-pro-text-to-video",
    "prompt": "A red balloon floating upward through blue sky",
    "duration": 5
  }' | jq -r '.generations[0].generation_id')

# Wait for it to finish
while true; do
  STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
    "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
  echo "$STATUS"
  case $STATUS in succeeded|failed|cancelled) break;; esac
  sleep 15
done

# Download the result.
curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
  "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.result_url' \
  | xargs curl -o output.mp4
```

## Start from an image or a video

Many video models also take an image (`input_image`) or a video (`input_video`), and some take audio.
Each model's [API reference](/inference-api/reference/model-references) lists what it accepts.

```bash
curl -X POST https://hub.oxen.ai/api/ai/queue \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-video-v2-6-pro-image-to-video",
    "prompt": "The camera pushes in slowly as the light shifts to dusk",
    "input_image": "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png",
    "duration": 5
  }'
```

## Get notified when it's ready

Instead of polling, subscribe to `GET /api/events` before you start the generation. You'll get an
event when the video is ready. See [completion events](/inference-api/reference/async_queue#completion-events).
