Video generation runs through the media queue. You submit a job, get a generation ID back right
away, then poll that ID until the video is ready. Expect anywhere from one to fifteen minutes
depending on the model and the duration you ask for.

## Generate a video

<CodeGroup>

```python Python
import os
import requests
import time

HEADERS = {
    "Authorization": f"Bearer {os.environ['OXEN_API_KEY']}",
    "Content-Type": "application/json",
}

enqueue = requests.post(
    "https://hub.oxen.ai/api/ai/queue",
    headers=HEADERS,
    json={
        "model": "kling-video-v2-6-pro-text-to-video",
        "prompt": "A red balloon floating upward through blue sky",
        "duration": 5,
    },
)
enqueue.raise_for_status()
generation_id = enqueue.json()["generations"][0]["generation_id"]
print(f"Enqueued {generation_id}")

while True:
    data = requests.get(
        f"https://hub.oxen.ai/api/ai/queue/{generation_id}",
        headers=HEADERS,
    ).json()
    print(f"  {data['status']}")
    if data["status"] in {"succeeded", "failed", "cancelled"}:
        break
    time.sleep(15)

if data["status"] != "succeeded":
    raise SystemExit(f"{data['status']}: {data['error_message']}")

with open("output.mp4", "wb") as f:
    f.write(requests.get(data["result_url"]).content)
print("Saved output.mp4")
```

```bash cURL
# Enqueue and capture the generation id.
GEN_ID=$(curl -s -X POST https://hub.oxen.ai/api/ai/queue \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-video-v2-6-pro-text-to-video",
    "prompt": "A red balloon floating upward through blue sky",
    "duration": 5
  }' | jq -r '.generations[0].generation_id')

# Poll until it finishes.
while true; do
  STATUS=$(curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
    "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.status')
  echo "$STATUS"
  case $STATUS in succeeded|failed|cancelled) break;; esac
  sleep 15
done

# Download the result.
curl -s -H "Authorization: Bearer $OXEN_API_KEY" \
  "https://hub.oxen.ai/api/ai/queue/$GEN_ID" | jq -r '.result_url' \
  | xargs curl -o output.mp4
```

## Start from an image or a video

Image-to-video and reference-to-video models take `input_image`, and video-to-video models take
`input_video`. Which one a model wants is part of its schema, and the model's own reference page
shows a working request.

```bash
curl -X POST https://hub.oxen.ai/api/ai/queue \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-video-v2-6-pro-image-to-video",
    "prompt": "The camera pushes in slowly as the light shifts to dusk",
    "input_image": "https://hub.oxen.ai/api/repos/elau/assets/file/main/bloxy/bloxy_cropped_512x512.png",
    "duration": 5
  }'
```

## Multi-shot video

Some models cut between shots within one generation. Pass `multi_prompt` with a prompt and duration
per shot instead of a single `prompt`.

```bash
curl -X POST https://hub.oxen.ai/api/ai/queue \
  -H "Authorization: Bearer $OXEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-video-o3-pro-reference-to-video",
    "multi_prompt": [
      {"prompt": "Wide shot: a bird takes off from a branch", "duration": 5},
      {"prompt": "Tracking shot: the bird soars through clouds", "duration": 5}
    ],
    "aspect_ratio": "16:9"
  }'
```

## Don't sit on a poll loop

Video takes minutes, so a completion event beats polling for it. Subscribe to
`GET /api/events` before you enqueue and you get told the moment the file lands. See
[completion events](/inference-api/reference/async_queue#completion-events).
